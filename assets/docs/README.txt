80G CERTIFICATE
===============

Put your trust's 80G registration certificate here as a PDF named EXACTLY:

    80G-certificate.pdf

Once this file exists, the "Download 80G Certificate" button on the
thank-you page becomes active automatically. If the file is missing,
the button hides and donors see "your 80G certificate will be emailed".

How to upload:
- Easiest: cPanel -> File Manager -> public_html/assets/docs/ -> Upload
- Or: place the PDF in this folder, then commit & push to GitHub and
  deploy (it will be copied to the server).

NOTE on Form 10BE (the legally valid per-donor 80G certificate):
This must be downloaded from the Income Tax portal AFTER you file
Form 10BD each year, then sent to each donor. The file here is your
trust's general 80G registration certificate.
